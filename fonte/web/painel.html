Endereços

Use o primeiro (com .local) quando possível: ele não muda mesmo que o roteador troque o número do PC. Se o celular não abrir o endereço .local, use o de números. O app do celular também encontra o PC sozinho pelo nome, mesmo que o número mude.

Instalar o app no celular

Com o celular na mesma Wi‑Fi, aponte a câmera para o QR Code e abra o arquivo baixado. O Android pode pedir para permitir a instalação de apps desta fonte.
